Zapisuj każdą zmianę algorytmiczną lub wydajnościową w osobnym pliku `NN-nazwa.md`, używając `../iteration-template.md`. Numeruj iteracje kolejno i podawaj commit/tag, wariant S0/S1/S2/P1/G1/G2/G3, profil, pomiary przed i po oraz decyzję.

Nie zastępuj wcześniejszych notatek wynikami późniejszych wersji. Odrzucone optymalizacje i uzasadnienie zakończenia pracy również należą do historii projektu.
